# Watchmaking School & HorLux Website Documentation

## Project Overview
A premium, multi-page website designed for a luxury horology academy named HorLux. The site features a sophisticated design system using a palette of Gold, Black, Silver, and Deep Navy, targeting high-end educational and craftsmanship standards.

## File Structure
- `/index.html`: Home 1 (General Overview)
- `/pages/home-2.html`: Home 2 (Cinematic/Mastery focus)
- `/pages/courses.html`: Course catalog and certification details
- `/pages/workshops.html`: Laboratory and training facility showcase
- `/pages/gallery.html`: Masonry-style student work gallery
- `/pages/admissions.html`: Application process, timeline, and FAQ
- `/pages/about.html`: Academy heritage and instructor team
- `/pages/contact.html`: Contact info, inquiry form, and location
- `/pages/login.html`: Split-screen authentication (Login)
- `/pages/signup.html`: Split-screen authentication (Signup)

## Assets
- `/assets/css/style.css`: Core layout and components
- `/assets/css/dark-mode.css`: Theme overrides
- `/assets/css/rtl.css`: Right-to-left layout support
- `/assets/js/main.js`: Interactivity, animations, and toggles
- `/assets/images/`: High-quality horology imagery (generated)

## Key Features
- **Luxury Aesthetic**: Glassmorphism, premium typography (Cormorant Garamond), and smooth transitions.
- **Theme/RTL Toggle**: Real-time switching between Light/Dark modes and LTR/RTL layouts.
- **Interactive Elements**: Animated statistics counters, reveal-on-scroll animations, and FAQ accordions.
- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop.
- **SEO Optimized**: Semantic HTML5 structure and meta tags included.

## Technical Requirements
- HTML5, CSS3 (Variables & Grid), Vanilla JavaScript.
- FontAwesome 6.4.0 (Icons).
- Google Fonts (Inter & Cormorant Garamond).
